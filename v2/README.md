# Air Hockey

Gra air hockey przeciwko AI, przygotowana w React, TypeScript i Vite.

## Funkcje

- Stół dostosowany do obrotu ekranu; w pionie gracz zawsze na dole.
- Wybór lewej lub prawej połowy w poziomie oraz koloru paletki.
- Cztery rozmiary stołu dopasowane do dostępnego miejsca, z obsługą dvh i safe-area.
- Ustawienia fizyki krążka oraz reakcji, przyspieszenia i wyprzedzenia ruchu paletki.
- PWA, pauza, limit czasu i limit punktów.

## Uruchomienie

```sh
npm ci
npm run dev
```

## Kompilacja

```sh
npm run build
```

Pliki wynikowe trafiają do `dist/`.
